
# Python Lyrics Player

## About the Project
A simple Python program that displays song lyrics line by line, pausing for three seconds between each line.

## Features
- Displays lyrics sequentially
- Uses Python's built-in `time` module
- Adds a timed delay between lines
- Simple beginner-friendly Python code

## Technologies Used
- Python
- `time` module

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

## How It Works
The program stores the lines in a Python list, loops through them, prints each line, and waits three seconds before continuing.

## Learning Objectives
- Python lists
- `for` loops
- Printing output
- Using `time.sleep()`
